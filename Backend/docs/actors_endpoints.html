Actors and Their Endpoints

This document lists the main actors in the system and the API endpoints they can access.

Actors

  • Registrar
  • Teacher
  • Student

Endpoints by Actor

Registrar - List all users
GET /api/users/
Returns a list of all users.
Request Example:
GET /api/users/ Authorization: Bearer <token>
Response Example:
{ "users": [ {"_id": "...", "email": "...", "role": "Registrar"} ] }
Registrar - List all teachers
GET /api/users/teachers
Returns a list of all teachers.
Request Example:
GET /api/users/teachers Authorization: Bearer <token>
Response Example:
{ "teachers": [ {"_id": "...", "email": "...", "role": "teacher"} ] }
Registrar - Manage user by ID
GET, PUT, DELETE /api/users/:id
Get, update, or delete a user by ID.
Request Example:
GET /api/users/123 Authorization: Bearer <token>
Response Example:
{ "_id": "...", "email": "...", "role": "Registrar" }
Registrar - List inactive courses
GET /api/courses/inactive
Returns a list of inactive courses.
Request Example:
GET /api/courses/inactive Authorization: Bearer <token>
Response Example:
{ "courses": [ {"_id": "...", "title": "...", "status": "inactive"} ] }
Registrar - Approve a course
PUT /api/courses/approve/:id
Approve a course by ID.
Request Example:
PUT /api/courses/approve/123 Authorization: Bearer <token>
Response Example:
{ "message": "Course approved" }
Registrar - Manage course categories
POST, GET /api/categories/
Create or list course categories.
Request Example:
GET /api/categories/ Authorization: Bearer <token>
Response Example:
{ "categories": [ {"_id": "...", "name": "..."} ] }
Registrar - List all modules
GET /api/modules/
Returns a list of all modules.
Request Example:
GET /api/modules/ Authorization: Bearer <token>
Response Example:
{ "modules": [ {"_id": "...", "title": "..."} ] }
Teacher - Create and list courses
POST, GET /api/courses/
Create a new course or list all courses.
Request Example:
POST /api/courses/ Authorization: Bearer <token> Content-Type: application/json { "title": "Course Title", "description": "..." }
Response Example:
{ "courses": [ {"_id": "...", "title": "..."} ] }
Teacher - Get course details
GET /api/courses/:courseid/details
Get details for a specific course.
Request Example:
GET /api/courses/123/details Authorization: Bearer <token>
Response Example:
{ "_id": "...", "title": "...", "modules": [...] }
Teacher - Create a module
POST /api/modules/:courseid/create
Create a new module for a course.
Request Example:
POST /api/modules/123/create Authorization: Bearer <token> Content-Type: application/json { "title": "Module Title", "content": "..." }
Response Example:
{ "message": "Module created", "module": {"_id": "...", "title": "..."} }
Teacher - Delete a module
DELETE /api/modules/:courseid/delete/:id
Delete a module by ID.
Request Example:
DELETE /api/modules/123/delete/456 Authorization: Bearer <token>
Response Example:
{ "message": "Module deleted" }
Teacher - Create an exam
POST /api/exams/
Create a new exam.
Request Example:
POST /api/exams/ Authorization: Bearer <token> Content-Type: application/json { "title": "Exam Title", "questions": [...] }
Response Example:
{ "message": "Exam created", "exam": {"_id": "...", "title": "..."} }
Teacher - Get exams for a module
GET /api/exams/module/:moduleId
Get all exams for a specific module.
Request Example:
GET /api/exams/module/123 Authorization: Bearer <token>
Response Example:
{ "exams": [ {"_id": "...", "title": "..."} ] }
Student - View enrolled courses with progress
GET /api/Enrollments/with-progress
View all enrolled courses and their progress.
Request Example:
GET /api/Enrollments/with-progress Authorization: Bearer <token>
Response Example:
{ "enrollments": [ {"course": "...", "progress": 50} ] }
Student - View module progress
GET /api/Enrollments/:courseid/modules/progress
View progress for all modules in a course.
Request Example:
GET /api/Enrollments/123/modules/progress Authorization: Bearer <token>
Response Example:
{ "modules": [ {"_id": "...", "progress": 80} ] }
Student - View a specific module
GET /api/Enrollments/:courseid/module/:moduleid
View details for a specific module.
Request Example:
GET /api/Enrollments/123/module/456 Authorization: Bearer <token>
Response Example:
{ "_id": "...", "title": "...", "content": "..." }
Student - Pay for a course
POST /api/Enrollments/pay/:id
Pay for a course by ID.
Request Example:
POST /api/Enrollments/pay/123 Authorization: Bearer <token>
Response Example:
{ "message": "Payment successful" }
Student - Submit exam answers
POST /api/Enrollments/exam/:examid/evaluate
Submit answers for an exam.
Request Example:
POST /api/Enrollments/exam/123/evaluate Authorization: Bearer <token> Content-Type: application/json { "answers": [...] }
Response Example:
{ "message": "Exam submitted", "score": 85 }
All - View notifications
GET /api/notifications/
View all notifications for the user.
Request Example:
GET /api/notifications/ Authorization: Bearer <token>
Response Example:
{ "notifications": [ {"_id": "...", "message": "..."} ] }
All - Login
POST /api/users/login
Authenticate and receive a JWT token.
Request Example:
POST /api/users/login Content-Type: application/json { "email": "user@example.com", "password": "Password@123!" }
Response Example:
{ "token": "..." }
All - Register
POST /api/users/register
Register a new user.
Request Example:
POST /api/users/register Content-Type: application/json { "fullName": "Test User", "email": "user@example.com", "password": "Password@123!", "confirmpassword": "Password@123!", "role": "student" }
Response Example:
{ "message": "Registration successful" }

Note: Some endpoints may require specific roles or ownership. See API docs for details.
